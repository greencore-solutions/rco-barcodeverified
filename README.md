# rco-barcodeverified

> The receipt a verified product match carries, a verifier anyone can use, and the keys issuers sign under.

Built and run by [wefetch](https://wefetch.ai/). This is the public connect kit, MIT. It holds no deploy code and no keys.

## Connect

This surface publishes for agents; it has no tool endpoint of its own.

- For agents: https://rco-barcodeverified.org/llms.txt
- Agent card: `https://rco-barcodeverified.org/.well-known/agent-card.json` (copy in this repo, `agent-card.json`)
- Site: https://rco-barcodeverified.org/

```bash
curl https://rco-barcodeverified.org/llms.txt
```
